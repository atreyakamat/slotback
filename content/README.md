# Content

Marketing content for SlotBack, kept apart from the app. Nothing in here is built, linted or typechecked by the app's CI.

| Folder | What goes in it |
| --- | --- |
| [`reels/`](reels) | Instagram Reels. `reels/studio` is the Remotion project for every reel, and finished posting files go in `reels/exports/`. |
| [`stories/`](stories) | Instagram Stories, 1080×1920. Safe area: 80px at the sides, 260px at the top, 360px at the bottom. |
| [`posts/`](posts) | Feed posts and carousels, 1080×1350 (4:5). |
| `brand/` | Logo files and brand source |
| [`deck/`](deck) | Pitch deck: PDF, slide PNGs and HTML source. |
| [`research/`](research) | Market research, the Goa lead pipeline and the prospect guide. |

**Brand:** ink `#07140F`, green `#0F2E22`, green light `#1A4434`, lime `#C6F432`, cream `#F5EFE1`, muted `#8FA89B`. Fonts are Archivo Black for display and Inter Tight 500/700/800 for body. The woff2 files are in `reels/studio/public/fonts/`.

**Naming:** `<topic>-<format>-v<n>.<ext>`, for example `launch-story-1080x1920-v1.png`.
